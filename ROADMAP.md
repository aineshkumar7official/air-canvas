# Roadmap
This document outlines the current features and future development phases for the Hand-Tracking Canvas application. 
## ✅ v1.0 (Current Release)

- **Core Tools:** Implemented fully functional Draw, Cursor, and Eraser modes.
- **Color Palette:** Built a custom UI color selection system with a hover to select mechanism. 
- **Canvas Capture:** Added a dedicated screenshot action to seamlessly capture and save user artwork.
- **Boundary Management:** Programmed "no-draw zones" and active edge warnings to prevent accidental inputs near system UI panels.
- **Welcome Screen:** Designed an initial welcome screen featuring an integrated hand calibration sequence.
- **Help & Docs:** Added an information button (`Info`) for quick access to instructions.
---

## 🛠️ Areas for Improvement (Current Backlog)
- **Fix hand-tracking false positives**: resolve the issue where standard hand movements are accidentally registered as fists and clear the screen.
- **Screenshot trigger:** the timer starts the moment you touch the camera icon instead of after holding for 1 second.
- **Tracking box:** the box is calculated but not used to crop or improve detection.
---
## 🚀 v2.0 Ideas

- **Partner Drawing Mode:** Allow two users to share, collaborate, and draw on the same physical or virtual canvas simultaneously.
- **Stylus & Tool Customization:** Introduce diverse pencil types, unique brush textures, and adjustable stroke weights.
- **Expanded Color Spectrum:** Upgrade the basic color palette to an advanced color wheel system. 
- **Gesture-Triggered Stencils:** Detect specific static hand shapes to instantly stamp shapes or pre-made stickers.
